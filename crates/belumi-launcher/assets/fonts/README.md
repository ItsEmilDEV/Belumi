# Bundled fonts

Both fonts are licensed under the SIL Open Font License 1.1. The full texts are in the `*-OFL.txt` files next to the fonts.

| Font | File | Author (per OFL) | Source |
| --- | --- | --- | --- |
| Pixelify Sans | `PixelifySans.ttf` | The Pixelify Sans Project Authors (https://github.com/eifetx/Pixelify-Sans) | https://github.com/google/fonts/tree/main/ofl/pixelifysans |
| Inter | `Inter.ttf` | The Inter Project Authors (https://github.com/rsms/inter) | https://github.com/google/fonts/tree/main/ofl/inter |

Both are variable fonts (weight axis; Inter also has optical size) whose default instance is Regular.
