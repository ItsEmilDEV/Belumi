## Belumi 0.1.0, the first release

Belumi is a Minecraft: Java Edition client and launcher written in Rust. It plays Minecraft 26.3 natively and 26.2 servers
through a translation layer, with its own launcher, voice chat, replays and a client screen you open with Right Shift.

### Highlights

- **Launcher** with Microsoft sign-in, a server list with live status, several accounts, an **Update now** button and Discord Rich Presence
- **Client screen (Right Shift):** a HUD builder (keystrokes, CPS, armor, effects with icons, FPS, ping, coordinates, clock, inventory) with undo, a crosshair editor with presets, chat tools, toggle sprint and sneak, freelook, shulker previews in tooltips
- **Voice chat** that works with Simple Voice Chat servers, in every build (push to talk on V)
- **Replays:** record a session, watch it with a free camera, speed and seek, set camera paths, save clips
- **Discord Rich Presence** that shows only what you choose: server, world, dimension, game mode, time
- **Plugins:** WebAssembly plugins for the client and for servers

### Download

| System | File |
|---|---|
| Any Linux (x86_64) | `belumi-0.1.0-linux-x86_64.tar.gz`, then `./install.sh` |
| Any Linux (x86_64), one file | `belumi-0.1.0-x86_64.AppImage` |
| Debian, Ubuntu, Mint | `belumi_0.1.0_amd64.deb` |
| Fedora, openSUSE | `belumi-0.1.0-1.x86_64.rpm` |
| Windows 10 and 11 (x64) | `belumi-0.1.0-windows-x64-setup.exe` (installer) or `belumi-0.1.0-windows-x64.zip` (portable) |

Every file has a `.sha256` next to it. Arch users can use the `PKGBUILD` in `packaging/`.

### Before you start

- You need your own copy of **Minecraft: Java Edition**. Belumi contains no Mojang files; the game needs resources prepared from your installation (see [docs/DEVELOPMENT.md](https://github.com/ItsEmilDEV/Belumi/blob/main/docs/DEVELOPMENT.md), "Prepared resources").
- The launcher's own Microsoft sign-in waits for Mojang's approval of its application; until then you can reuse an account from Prism Launcher, or play offline.
- Linux needs a Vulkan driver, ALSA and libopus (the AppImage brings libopus along). Windows needs a current graphics driver.
- Windows may show "Unknown publisher": the files are not code-signed yet. Choose "More info", then "Run anyway".

### Known limits

- Early development: expect rough edges, and please report what you find.
- The Windows build and the installer are new; the update button works for the Linux archive and the Windows zip or installer, not for the AppImage, the `.deb` or the `.rpm` (use the new file or your package manager).
