# Belumi 0.1.0 beta 9

A prerelease on top of beta 7. Beta 8's Linux build failed (a build script was not executable), so this is the first build with everything below.

- **Download and prepare**: when the game's files are missing, the launcher offers to fetch them itself. After you sign in, it downloads Minecraft from Mojang's own servers (checked file by file, with Mojang's Java if you have none) and prepares it, about 1 GB of download and a few minutes. No Minecraft install or extra tools are needed any more. Also `belumi-launcher --setup`. Only a small `horizon-files` folder ships with Belumi, never a Minecraft file. Tested on Linux; Windows is untested, please report problems.
- **Uninstall** (Settings): only cache and usage data, only the app, or everything (worlds and screenshots only if you tick it), with the list of what is deleted to confirm. `uninstall.sh --cache` and `--all` do the same on Linux.
- **Pat**, reworked: every press is a stroke and you can click as fast as you like; holding strokes on evenly. A quick press and spring-back on the creature, a brushing rustle, hearts, and creatures answer in their own voice now and then. Other Belumi players see it too, including your arm swinging with each stroke. Tune it in `belumi-patpat.json` (`period`, `volume`, `strength`).
- Windows: the Belumi icon in the launcher, the game, the installer and the uninstall entry (it showed no icon or Horizon's before).
